# Challenge Pot

Challenge-uri între prieteni, cu mize în £. Aplicația ține doar evidența (cine a pariat, cine a câștigat, cine cui datorează); banii se trimit direct între prieteni.

- Site: https://lucyan106-design.github.io/challenge-pot/
- Date: Supabase (proiectul „Lucian Challenges Friends”), protejate cu row-level security
- Baza de date: `database/supabase.sql`
